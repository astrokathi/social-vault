Production Mobile Architecture Cheat Sheet

Quick reference for Local-First Storage, OS Share Sheet Interception, and Infinite Loops.

1. The Core Architecture Loop

[OS Share Sheet (ACTION_SEND)] │ ▼ (URL Sanitizer: strip ?igsh=...) [ShareCollectionSheet Modal] │ ▼ (OpenGraph Crawler: og:image, og:video) [LocalAssetManager] ──(Streams binary bytes)──> `getApplicationDocumentsDirectory()/vault_media/` │ ▼ (Drift SQLite ORM) [Indexed Relational Database] │ ▼ (Reactive StreamProvider: watchFeedQueue()) [Endless PageView.builder (rawIndex % length)] │ ▼ (60Hz UI Bar & 1Hz Throttled SQLite Write) [AdaptiveScaffold (Mobile BottomBar / Tablet 2-Pane Split View)]

2. Drift Database Indexing Patterns

// 1. Unique shortcode prevents saving duplicate Reels
@TableIndex(name: 'idx_media_shortcode', columns: {#shortcode}, unique: true)

// 2. Collection foreign-key index speeds up folder filtering
@TableIndex(name: 'idx_media_collection', columns: {#collectionId})

// 3. Progress index enables instantaneous "Hide Watched (100%)" predicate filtering
@TableIndex(name: 'idx_media_progress', columns: {#watchProgress})

3. The Modulo Infinite Scroll Formula

// Leave itemCount null to trigger infinite scrolling
PageView.builder(
  scrollDirection: Axis.vertical,
  itemBuilder: (context, rawIndex) {
    // Modulo ensures index cycles endlessly without boundary crashes
    final item = items[rawIndex % items.length];
    return item.mediaType == MediaType.carousel
        ? CarouselMediaItem(item: item)
        : ReelVideoItem(item: item);
  },
)
