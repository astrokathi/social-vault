1. The Relative Path Sandbox Trap

On iOS, every app rebuild or launch generates a new container UUID: /var/mobile/Containers/Data/Application/<UUID>/Documents. Storing relative paths like vault_media/C8kP.../thumb.jpg in SQLite protects data across UUID rotations, but passing this string directly to Image.network() crashes because Flutter interprets it as an invalid HTTP host.

2. Default System Collections vs. User Collections

Features like "Favorites" must exist permanently as system collections:

  • Protected Key: Hardcoded ID col_favorites seeded at database creation.
  • Creation Guard: Custom folder modal rejects user input named "Favorites" to prevent duplicate collision.
  • Deletion Guard: Popup menu hides the "Delete" option for system-flagged collections.
  • Query Union: watchMediaForCollection('col_favorites') returns both items with collectionId == 'col_favorites' AND items flagged isFavorite == true.

3. Anti-Plagiarism & Creator Attribution UX

Saving third-party media requires honoring the original creators. ReelVault implements:

  1. Regex Extractors: Captures true @handles from title and OpenGraph metadata.
  2. Verified Creator Badge: Verified shield badge with author identity next to every video.
  3. Expandable Full Captions: Tapping the description reveals complete hashtags, credits, and links.
