Adaptive Layouts & Multi-Device Breakpoints

Responsive Viewports, NavigationRail vs BottomNavigationBar, and Tablet 2-Pane Split-Views.

1. The Multi-Device Reality

Mobile developers often design solely for standard smartphones (e.g. 390pt width). But users run Flutter apps on compact devices (iPhone SE, 375pt), massive flagships (iPhone 16 Pro Max, 430pt), foldable inner displays, and tablets (iPad Pro, 834pt+).

Stretching a vertical 9:16 reel to full-screen on an iPad distorts the layout and wastes 60% of horizontal screen real estate.

2. Breakpoint Architecture

┌───────────────────────┬────────────────────────┬────────────────────────────────────────┐ │ Device Class │ Width Breakpoint │ Adaptive Navigation & Screen Strategy │ ├───────────────────────┼────────────────────────┼────────────────────────────────────────┤ │ Compact Mobile │ < 390dp │ 56dp BottomNavigationBar + 3 Col Grid │ │ Large Mobile │ 390dp – 699dp │ Edge-to-Edge BottomBar + 3 Col Grid │ │ Tablet / Foldable │ >= 700dp │ 80dp NavigationRail + 2-Pane Split View│ └───────────────────────┴────────────────────────┴────────────────────────────────────────┘

In lib/core/responsive/adaptive_scaffold.dart, we use LayoutBuilder to monitor viewport changes continuously: 

LayoutBuilder(
  builder: (context, constraints) {
    final isTablet = constraints.maxWidth >= 700;
    return isTablet
        ? _buildTabletLayout(context, constraints)
        : _buildMobileLayout(context);
  },
)

3. The Tablet 2-Pane Split View

On wide screens, instead of letterboxing black bars around the video, ReelVault partitions the screen into two coordinated panes:

  • Left Pane (Flex 7): Full-height video player with top floating sequence controls.
  • Right Pane (Flex 5): Live Active Queue Inspector displaying thumbnail cards, author handles, and watch progress percentages for every upcoming Reel in the queue. Tapping any item jumps immediately to that reel.
