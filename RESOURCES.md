# ReelVault Flutter Architecture Resources

## Knowledge

- [Drift Documentation](https://drift.simonbinder.eu/)
  Official docs for Drift (formerly Moor). Use for: reactive SQLite streams, foreign keys, migrations, and schema generator.
- [Riverpod Official Guide](https://riverpod.dev/)
  Core documentation for modern Flutter state management. Use for: `StreamProvider`, `StateNotifierProvider`, and auto-disposing logic.
- [Flutter Adaptive Scaffold & Multi-Screen Guidelines](https://docs.flutter.dev/ui/layout/responsive/adaptive-apps)
  Official Flutter documentation on adaptive design. Use for: `LayoutBuilder`, `NavigationRail`, and breakpoint transitions across foldables/tablets.
- [Android Intents and Intent Filters](https://developer.android.com/guide/components/intents-filters)
  Android documentation on `ACTION_SEND`. Use for: configuring `singleTask` launch modes and receiving text mime-types.
- [Apple Developer: Share App Extensions](https://developer.apple.com/design/human-interface-guidelines/app-extensions)
  Apple HIG and developer docs. Use for: iOS Share Extension targets and App Group sandbox sharing.

## Wisdom (Communities)

- [r/FlutterDev Subreddit](https://reddit.com/r/FlutterDev)
  Active community for production Flutter practitioners, state management debates, and library evaluations.
- [Drift Discord & GitHub Discussions](https://github.com/simolus3/drift/discussions)
  Direct support and architectural patterns from Simon Binder and SQLite experts.
